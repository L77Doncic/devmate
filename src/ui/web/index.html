    配置你的 API Key

    打开左侧栏底部「设置」，填 DeepSeek 的密钥（默认 base_url 已就绪）。只保存在你自己的机器上。

    描述你想做什么

    下面输入框直接打字。例如：「把我的代码改成零依赖」或「帮我看一下这个报错」。Enter 发送、Shift+Enter 换行。

    常规
    
            
    界面外观与运行环境；密钥与端点见「模型接口」。
    
            
    
              
    
                主题
                
    
                  
                  
                  
                
    
                
    
                  「跟随系统」随操作系统深浅色实时切换（浏览器无痕模式不记忆选择）。
                
    
              
    
              
    
                工作区目录
                （服务端未提供）
                
    仅展示确认；工作目录由 DevMate 启动位置决定。
    
              
    
            
    
            
            
    
              
    
                Subagent 工作流
                
              
    
              
    
                
                
                
    
                  启用后 DevMate 可将独立子任务（子代理）并行执行；范围为 1-4，不接受 0。
                
    
                
    
              
    
            
    
            
            
    
              
    
                方法论先行
                
              
    
              
    
                开启：本轮第一个工具调用前自动加载命中的方法技能（use_skill）；未加载的方法技能调用将被拦截并提示。
                关闭：方法技能仅作参考，不自动加载、不拦截。
              
    
            
    
            
            
    
              
    
                收尾评审（独立审查）
                
              
    
              
    
                开启：任务有实质变更（写入/编辑/命令执行/MCP
                调用/子代理）时，收尾自动派独立审查子代理，交付物对照任务目标列出缺陷后收尾。
                关闭：仅提示不强制，收尾评审不作要求。
              
    
            
    
          
    
          
          
    
            
    模型接口
    
            
    
              填写 OpenAI 兼容端点的 Base URL、模型与密钥（主默认 DeepSeek）。
            
    
            
    
              
    
                DevMate
                openai-compatible
              
    
              
    
                
                
                
    任意 OpenAI 兼容端点；主默认 DeepSeek。
    
              
    
              
    
                
                
              
    
              
    
                
                
                
    未配置
    
                
    
                  密钥只保存在你本机的服务端；保存后输入框立即清空，页面内永久只显示掩码。
                
    
              
    
              
    
              
    
                
                
                
              
    
            
    
          
    
          
          
    
            
    Skills
    
            
    
              技能是可由 DevMate 按需调用的子工作流；列表由服务端提供，此处只控制启用状态。

                  技能目录即插即用：把含 SKILL.md 的目录放进 ~/.devmate/skills/<id>/，
                  点「重新扫描」即可出现在列表。
