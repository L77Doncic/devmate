    常规
    
            
    界面外观与运行环境；密钥与端点见「模型接口」。
    
            
    
              
    
                主题
                
    
                  
                  
                  
                
    
                
    
                  「跟随系统」随操作系统深浅色实时切换（浏览器无痕模式不记忆选择）。
                
    
              
    
              
    
                工作区目录
                （由启动目录决定）
                
    
                  仅展示确认；未显式选择时，工作目录由 DevMate 启动位置决定。
                
    
              
    
            
    
            
            
    
              
    
                Subagent 工作流
                
              
    
              
    
                
                
                
    
                  启用后 DevMate 可将独立子任务（子代理）并行执行：1-8 为显式并行数； 0 =
                  无上限（按需派遣），并行子任务数按主 agent 判断需要任意派遣。
                
    
                
    
                
    
              
    
            
    
            
            
    
              
    
                方法论先行
                
              
    
              
    
                开启：本轮第一个工具调用前自动加载命中的方法技能（use_skill）；未加载的方法技能调用将被拦截并提示。
                关闭：方法技能仅作参考，不自动加载、不拦截。
              
    
            
    
            
            
    
              
    
                收尾评审（独立审查）
                
              
    
              
    
                开启：任务有实质变更（写入/编辑/命令执行/MCP
                调用/子代理）时，收尾自动派独立审查子代理，交付物对照任务目标列出缺陷后收尾。
                关闭：仅提示不强制，收尾评审不作要求。
              
    
            
    
          
    
          
          
    
            
    模型接口
    
            
    
              填写 OpenAI 兼容端点的 Base URL、模型与密钥（主默认 DeepSeek）。
            
    
            
    
              
    
                DevMate
                openai-compatible
              
    
              
    
                
                
                
    任意 OpenAI 兼容端点；主默认 DeepSeek。
    
              
    
              
    
                
                
                
    
              
    
              
    
                
                
                
    
                  请求侧单请求输入上限（max_input_tokens），必填正整数。仅 DashScope/Qwen
                  等白名单供应商支持发送；其余供应商（含 DeepSeek）不发送该字段
                  （档位由模型固有上下文决定）。
                
    
                
    
                
    
              
    
              
    
                
                
                
    
                  请求侧单请求输出上限（max_tokens），必填正整数；未设置时按缺省 8192
                  （DEFAULT_MAX_TOKENS）回填。超过模型上限的值保存时按供应商上限钳制
                  （提示「已按上限钳制为 N」）。
                
    
                
    
                
    
              
    
              
    
                
                
                
    未配置
    
                
    
                  密钥只保存在你本机的服务端；保存后输入框立即清空，页面内永久只显示掩码。
                
    
              
    
              
    
              
    
                
                
                
              
    
            
    
          
    
          
          
    
            
    Skills
    
            
    
              技能是可由 DevMate 按需调用的子工作流；列表由服务端提供，此处只控制启用状态。
            
    
            
    
              
    
                安装技能
              
    
              
    
                
                
    
                  
                  
                
    
                
                
    
                  URL 支持常见公共代码托管；均要求入口文件为 SKILL.md。
                
    
                
    
                  
                  
                
    
                
    
                
    
                  技能目录即插即用：把含 SKILL.md 的目录放进 ~/.devmate/skills/<id>/，
                  点「重新扫描」即可出现在列表。
